# EKHorus - Repositorio para Kodi

Reproductor AceStream para Kodi (adaptacion de Horus para EspaKodi).

Repositorio e instrucciones: https://espakodi.github.io/EKHorus/

## Instalacion rapida
1. Kodi -> Gestor de archivos -> Anadir origen -> `https://espakodi.github.io/EKHorus/`
2. Add-ons -> Instalar desde zip -> `repository.ekhorus-1.0.0.zip`
3. Instalar desde repositorio -> EKHorus Repository -> EKHorus
