Cómo instalar EKHorus

Desde repositorio (recomendado — recibe actualizaciones automáticas)

  1. En Kodi: Ajustes → Explorador de archivos → Añadir fuente.
  2. En <Ninguno> introduce esta dirección exacta:

    https://espakodi.github.io/EKHorus/
    Importante: la URL debe terminar en .io/EKHorus/ (respeta las mayúsculas de EKHorus).
  3. Ponle de nombre EKHorus y pulsa OK.
  4. Ve a Add-ons → icono de paquete (esquina superior izquierda) → Instalar desde archivo zip.
    (Si aparece el aviso de seguridad: Ajustes → Sistema → Add-ons → activa "Orígenes desconocidos").
  5. Selecciona la fuente EKHorus → repository.ekhorus-1.0.0.zip.
  6. Cuando aparezca "Add-on instalado", ve a Instalar desde repositorio → EKHorus Repository → Add-ons de programa → EKHorus → Instalar.

Desde ZIP (instalación manual sin actualizaciones automáticas)

  1. Descarga script.module.horus-1.3.2.zip desde https://espakodi.github.io/EKHorus/script.module.horus/.
  2. En Kodi: Add-ons → icono de paquete → Instalar desde archivo zip → selecciona el archivo descargado.
